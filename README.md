# 🎨 Face-Det-for-insider-info-using-mtcnn

> ✨ **Face Detection Utilities using MTCNN (Multi-task Cascaded Convolutional Networks)**


## 🌟 Project Summary

This project provides a simple and powerful toolkit that uses **MTCNN** to detect faces in:

* 🖼️ **Images**
* 📸 **Webcam streams**

The tool extracts:

* 🟩 **Bounding boxes**
* 🎯 **Facial landmarks (eyes, nose, mouth)**
* ✂️ **Cropped face images**
* 📊 **CSV summary** of detections

It's lightweight, flexible, and useful for face recognition preprocessing, dataset creation, and demos.



## 🚀 Key Features

* 🤖 **Accurate Face Detection** using MTCNN
* 📷 Works with **images, videos, and webcam**
* 📝 Saves **detection metadata** (bbox + confidence + landmarks)
* ✂️ Exports **cropped faces** automatically
* 💻 Easy **CLI commands** + Python API example
